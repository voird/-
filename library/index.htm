Awesome Neural CAD

Подборка научных публикаций и разработок, посвященных применению нейронных сетей в автоматизированном проектировании. Материалы позволяют ознакомиться с современными подходами к созданию и обработке трехмерных CAD-моделей.

Авторы: Коллектив авторов.

Тип материала: Научный проект.

Источник: Официальный сайт Awesome Neural CAD

CADDreamer: CAD Object Generation from Single-view Images

Исследование посвящено автоматической генерации трехмерных CAD-объектов по изображению с одного ракурса. Представленный подход представляет интерес для изучения методов восстановления геометрии объектов при ограниченном количестве исходных данных.

Авторы: Коллектив авторов.

Тип материала: Научная статья.

Источник: arXiv — CADDreamer

Дата обращения: 02.07.2026

BrepDiff: Single-Stage B-rep Diffusion Model

Работа рассматривает применение диффузионных моделей для генерации трехмерных объектов в формате B-rep. Особое внимание уделяется восстановлению геометрических поверхностей и структурных элементов CAD-моделей. Исследование полезно для изучения современных нейросетевых методов параметрического моделирования.

Авторы: Коллектив авторов.

Тип материала: Научный проект.

Источник: Официальный сайт BrepDiff

Дата обращения: 03.07.2026

BrepDiff: Single-Stage B-rep Diffusion Model (публикация)

Научная публикация, в которой рассматривается одноэтапная диффузионная архитектура для генерации граничного представления трехмерных объектов. Материал дополняет описание проекта BrepDiff и позволяет изучить его методологическую основу.

Авторы: Коллектив авторов.

Тип материала: Научная публикация.

Источник: ACM Digital Library

CLR-Wire: Towards Continuous Latent Representations for 3D Curve Wireframe Generation

Исследование посвящено генерации трехмерных каркасных представлений объектов с использованием непрерывных латентных пространств. Рассматриваются методы построения пространственных кривых и связей между геометрическими элементами. Работа представляет интерес для изучения восстановления структуры трехмерных объектов.

Авторы: Коллектив авторов.

Тип материала: Научная статья.

Источник: arXiv — CLR-Wire

Дата обращения: 12.07.2026
