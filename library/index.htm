Собственные публикации и доклады

  1. Awesome Neural CAD
    Авторы: Коллектив авторов
    Описание: Подборка материалов и научных разработок, связанных с применением нейронных сетей для автоматизированного проектирования и генерации CAD-моделей.
    Источник: Официальный сайт. — URL: https://bunnysocrazy.com/ (дата обращения: 05.01.2026).
  2. CADDreamer. CAD Object Generation from Single-view Images
    Авторы: Коллектив авторов
    Описание: Научная работа, посвященная генерации трехмерных CAD-объектов на основе изображений с одного ракурса.
    Источник: arXiv. — URL: https://arxiv.org/abs/2502.20732 (дата обращения: 02.07.2026).
  3. BrepDiff. Single-stage B-rep Diffusion Model
    Авторы: Коллектив авторов
    Описание: Представлен диффузионный подход к генерации трехмерных моделей в формате B-rep, позволяющий восстанавливать геометрические поверхности и структуру CAD-объектов.
    Источник: Официальный сайт. — URL: https://brepdiff.github.io/ (дата обращения: 03.07.2026).
  4. BrepDiff: Single-Stage B-rep Diffusion Model
    Авторы: Коллектив авторов
    Описание: Научная публикация, описывающая одноэтапную диффузионную модель для генерации граничного представления трехмерных геометрических объектов.
    Источник: ACM Digital Library. — URL: https://dl.acm.org/doi/10.1145/3721238.3730698.
  5. CLR-Wire. Towards Continuous Latent Representations for 3D Curve Wireframe Generation
    Авторы: Коллектив авторов
    Описание: Исследование посвящено использованию непрерывных латентных представлений для генерации трехмерных каркасных моделей, состоящих из кривых и соединяющих их элементов.
    Источник: arXiv. — URL: https://arxiv.org/abs/2504.19174 (дата обращения: 12.07.2026).
