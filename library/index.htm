1. Распознавание дефектов печати 3D принтера на изображении

Сторожева П.А., Уварова А.В. — Кубанский государственный университет

Научная работа посвящена применению нейронных сетей для обнаружения и классификации дефектов при 3D-печати. Рассматривается использование архитектуры YOLOv8, подготовка обучающей выборки и реализация программы автоматического распознавания дефектов на изображениях.

2. Система контроля процесса 3D печати в реальном времени

Сторожева П.А. — Выпускная квалификационная работа, КубГУ, 2025

Работа посвящена разработке клиент-серверной системы контроля качества 3D-печати с использованием нейронной сети YOLO и Django REST Framework. Рассматриваются архитектура программного обеспечения, обучение модели и применение системы для обнаружения дефектов печати.

Открыть работу (PDF)

3. Веб-программирование и веб-сервисы

Синица С.Г. — Учебное пособие, Кубанский государственный университет, 2013

Учебное пособие содержит теоретические и практические материалы по веб-разработке, архитектуре Всемирной паутины, протоколу HTTP, безопасности веб-приложений и технологиям построения веб-сервисов. Рассматриваются основы HTML, JavaScript, PHP и системы управления контентом Drupal.

Научные публикации и исследования

В электронной библиотеке собраны научные публикации, посвященные методам восстановления трехмерной геометрии по изображениям, нейросетевым архитектурам, представлению трехмерных объектов и генерации CAD-моделей. Представленные работы используются для изучения существующих подходов и определения направлений разработки системы реконструкции трехмерных моделей.

01. BrepDiff: A Diffusion Model for B-rep Generation

Научная публикация, ACM Digital Library, 2025

Исследование посвящено генерации граничных представлений трехмерных объектов с использованием диффузионных моделей. Работа представляет интерес для изучения восстановления геометрически корректных CAD-моделей.

Открыть публикацию

02. CLR-Wire

Научная публикация, arXiv, 2025

Работа рассматривает построение трехмерных моделей на основе структурированного представления геометрических ребер и контуров. Материал полезен для изучения способов восстановления каркасной структуры объекта.

Открыть публикацию

03. CADDreamer

Научная публикация, arXiv, 2025

Исследование посвящено применению генеративных моделей для создания CAD-геометрии. Рассматриваемые подходы могут использоваться при разработке систем автоматического построения трехмерных объектов.

Открыть публикацию

04. BrepGen: A B-rep Generative Model

Научная публикация, arXiv, 2024

Работа рассматривает генерацию параметрических трехмерных объектов в формате B-rep. Представляет интерес с точки зрения структурированного описания геометрии и создания CAD-моделей.

Открыть публикацию

05. Mesh R-CNN

Gkioxari G., Malik J., Johnson J., ICCV, 2019

Метод нейросетевой реконструкции трехмерных сеток по изображениям. Архитектура сочетает обнаружение объектов и построение их трехмерного представления.

Открыть публикацию

06. Pixel2Mesh: Generating 3D Mesh Models from Single RGB Images

Wang N. et al., ECCV, 2018

В публикации предложен метод последовательного преобразования признаков изображения в трехмерную полигональную сетку. Работа является одним из примеров восстановления геометрии объекта по одному изображению.

Открыть публикацию

07. MVSNet: Depth Inference for Unstructured Multi-view Stereo

Yao Y. et al., ECCV, 2018

Исследование посвящено восстановлению глубины сцены по нескольким изображениям с разных ракурсов. Предложенный подход представляет интерес для реализации многовидовой реконструкции.

08. DeepSDF: Learning Continuous Signed Distance Functions

Park J. J. et al., CVPR, 2019

В работе рассматривается непрерывное представление трехмерной геометрии с помощью нейронной сети, аппроксимирующей функцию знакового расстояния. Метод может применяться для восстановления поверхности объекта.

Mescheder L. et al., CVPR, 2019

Авторы предлагают представлять трехмерные объекты с помощью непрерывной функции занятости пространства. Работа полезна для изучения альтернативных способов кодирования трехмерной формы.

Mildenhall B. et al., ECCV, 2020

Исследование посвящено представлению трехмерных сцен с помощью нейронных радиационных полей. Метод использует набор изображений с известными параметрами камер для синтеза новых ракурсов сцены.
