Перечень информационных ресурсов

В данном разделе представлены интернет-ресурсы, используемые при изучении технологий машинного обучения, компьютерного зрения, обработки изображений и трехмерной геометрии. Список включает официальную документацию программных библиотек, источники наборов данных, инструменты трехмерного моделирования, научные поисковые системы и справочные материалы.

1. Библиотеки и фреймворки машинного обучения

1. PyTorch

Официальная документация фреймворка для разработки и обучения нейронных сетей.

https://pytorch.org/docs/stable/index.html

2. PyTorch — Conv3d

Описание трехмерной свертки, используемой при обработке объемных данных и построении 3D-нейросетей.

https://pytorch.org/docs/stable/generated/torch.nn.Conv3d.html

3. TensorFlow

Официальная документация платформы машинного обучения TensorFlow.

https://www.tensorflow.org/overview

4. TensorFlow — Conv3D

Документация трехмерного сверточного слоя для обработки объемных тензоров.

https://www.tensorflow.org/api_docs/python/tf/keras/layers/Conv3D

5. Keras

Руководство по созданию, настройке и обучению моделей глубокого обучения.

https://keras.io/

6. NumPy

Документация библиотеки для работы с многомерными массивами и математическими операциями.

https://numpy.org/doc/

7. SciPy

Инструменты научных вычислений, обработки данных и математического анализа.

https://docs.scipy.org/doc/scipy/

8. scikit-learn

Библиотека алгоритмов машинного обучения и средств оценки качества моделей.

https://scikit-learn.org/stable/

9. OpenCV

Библиотека компьютерного зрения для обработки изображений, выделения признаков и геометрических преобразований.

https://docs.opencv.org/

10. Matplotlib

Документация библиотеки визуализации данных и построения графиков результатов экспериментов.

https://matplotlib.org/stable/contents.html

11. Pillow

Библиотека обработки растровых изображений, изменения размеров и преобразования графических форматов.

https://pillow.readthedocs.io/

12. NVIDIA CUDA Toolkit

Средства разработки и выполнения вычислений на графических процессорах NVIDIA.

https://developer.nvidia.com/cuda-toolkit

13. NVIDIA cuDNN

Библиотека ускорения операций глубокого обучения на графических процессорах.

https://developer.nvidia.com/cudnn

2. Инструменты трехмерной обработки и моделирования

14. PyTorch3D

Библиотека для работы с трехмерными структурами данных, сетками, точечными облаками и дифференцируемым рендерингом.

https://pytorch3d.org/

15. trimesh

Инструмент Python для загрузки, анализа, преобразования и сохранения трехмерных полигональных моделей.

https://trimesh.org/

16. Pyrender

Библиотека визуализации трехмерных объектов и получения изображений моделей с заданных ракурсов.

https://pyrender.readthedocs.io/

17. Open3D

Средства обработки трехмерных данных, облаков точек, полигональных сеток и восстановления поверхностей.

https://www.open3d.org/docs/latest/

18. COLMAP

Программная система для трехмерной реконструкции по набору изображений и определения параметров камер.

https://colmap.github.io/

19. Open CASCADE Technology

Платформа для построения и обработки CAD-геометрии, работы с поверхностями, кривыми и граничными представлениями.

https://dev.opencascade.org/doc/overview/html/

20. FreeCAD Documentation

Документация системы автоматизированного проектирования FreeCAD и ее инструментов обработки геометрии.

https://wiki.freecad.org/

21. Blender Manual

Руководство по трехмерному моделированию, визуализации, работе с сетками и экспорту объектов.

https://docs.blender.org/manual/en/latest/

22. VTK Documentation

Инструментарий для визуализации научных данных, трехмерной графики и обработки геометрических объектов.

https://vtk.org/documentation/

23. CGAL

Библиотека алгоритмов вычислительной геометрии, включая обработку поверхностей и полигональных сеток.

https://www.cgal.org/documentation.html

24. libigl

Библиотека геометрической обработки сеток и выполнения операций над трехмерными поверхностями.

https://libigl.github.io/

25. MeshLab

Программное обеспечение для редактирования, очистки, анализа и преобразования трехмерных сеток.

https://www.meshlab.net/

26. Assimp

Библиотека импорта и экспорта трехмерных моделей в различных форматах.

https://assimp.org/

3. Наборы данных трехмерных моделей

27. ABC Dataset

Набор CAD-моделей с параметрическими кривыми и поверхностями, предназначенный для исследований геометрического глубокого обучения.

https://deep-geometry.github.io/abc-dataset/

28. ShapeNet

Крупный набор трехмерных объектов различных категорий, применяемый для обучения и оценки алгоритмов реконструкции.

https://shapenet.org/

29. Pix3D

Набор изображений реальных объектов, связанных с соответствующими трехмерными моделями. Используется в задачах восстановления формы по изображению.

https://pix3d.csail.mit.edu/

30. Objaverse

Масштабная коллекция аннотированных трехмерных объектов, пригодная для исследований генерации и обработки 3D-контента.

https://objaverse.allenai.org/

31. ModelNet

Набор трехмерных CAD-объектов, широко используемый при исследовании классификации и распознавания геометрических форм.

https://modelnet.cs.princeton.edu/

32. Thingi10K

Коллекция моделей для 3D-печати, предназначенная для изучения геометрии и качества полигональных сеток.

https://github.com/Thingi10K/Thingi10K

33. Fusion 360 Gallery Dataset

Набор параметрических CAD-моделей, содержащий информацию о последовательности операций проектирования.

https://github.com/AutodeskAILab/Fusion360GalleryDataset

34. DeepCAD

Набор CAD-моделей и программных средств для исследования генерации трехмерных объектов на основе последовательностей операций проектирования.

https://github.com/ChrisWu1997/DeepCAD

4. Научные архивы и поисковые системы

35. arXiv — Computer Vision

Научный архив публикаций по компьютерному зрению и распознаванию образов.

https://arxiv.org/list/cs.CV/recent

36. CVF Open Access

Электронная библиотека публикаций конференций по компьютерному зрению и распознаванию образов.

https://openaccess.thecvf.com/

37. ACM Digital Library

Научная электронная библиотека публикаций в области вычислительной техники, компьютерной графики и информационных технологий.

https://dl.acm.org/

38. IEEE Xplore

Электронная база научных статей, конференционных материалов и технических стандартов.

https://ieeexplore.ieee.org/

39. Google Scholar

Поисковая система для поиска научных публикаций, авторов и цитирований.

https://scholar.google.com/

40. Papers with Code

Платформа для поиска научных исследований, программных реализаций и результатов сравнения алгоритмов машинного обучения.

https://paperswithcode.com/
