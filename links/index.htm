Перечень ссылок по теме магистерской работы

Разработка системы для реконструкции 3D-моделей по изображениям

Сторожева Полина Антоновна

В данном разделе собраны научные публикации, наборы данных, программные средства и электронные ресурсы, которые используются для изучения методов восстановления трехмерной геометрии по изображениям. Каждая запись содержит название ресурса, сведения об авторах или организации и краткую аннотацию его содержания и полезности для темы исследования.

Всего ресурсов в перечне: 34.

Научные публикации и современные методы реконструкции

  1. BrepDiff: Single-stage B-rep Diffusion Model

    Авторы: Mingi Lee, Dongsu Zhang, Clément Jambon, Young Min Kim.

    Аннотация: Научная работа, представленная на SIGGRAPH 2025, посвящена диффузионной генерации CAD-моделей в формате B-Rep. Авторы рассматривают способы создания и редактирования геометрии, включая дополнение, объединение и интерполяцию моделей. Ресурс особенно полезен для изучения нейросетевых методов, ориентированных на получение редактируемой CAD-геометрии.

    Перейти к ресурсу — https://brepdiff.github.io/

  2. CLR-Wire: Towards Continuous Latent Representations for 3D Curve Wireframe Generation

    Авторы: Xueqi Ma, Yilin Liu, Tianlong Gao, Qirui Huang, Hui Huang.

    Аннотация: Публикация SIGGRAPH 2025 описывает генерацию трехмерных каркасных моделей с помощью непрерывного латентного представления. Метод объединяет геометрию кривых и топологические связи между ними. Материал полезен при анализе способов восстановления ребер и вершин трехмерного объекта.

    Перейти к ресурсу — https://arxiv.org/abs/2504.19174

  3. CADDreamer: CAD Object Generation from Single-view Images

    Авторы: Yuan Li, Cheng Lin, Yuan Liu, Xiaoxiao Long, Chenxu Zhang, Ningna Wang, Xin Li, Wenping Wang, Xiaohu Guo.

    Аннотация: Статья CVPR 2025 рассматривает генерацию CAD-объектов по одному изображению. Предложенный подход использует многовидовую диффузионную модель и геометрическую оптимизацию для получения B-Rep-представления. Источник непосредственно соответствует тематике реконструкции трехмерных моделей по изображениям.

    Перейти к ресурсу — https://openaccess.thecvf.com/content/CVPR2025/html/Li_CADDreamer_CAD_Object_Generation_from_Single-view_Images_CVPR_2025_paper.html

  4. BrepGen: A B-rep Generative Diffusion Model with Structured Latent Geometry

    Авторы: Xiang Xu, Joseph G. Lambourne, Pradeep Kumar Jayaraman, Zhengqing Wang, Karl D. D. Willis, Yasutaka Furukawa.

    Аннотация: В статье представлен диффузионный метод генерации B-Rep-моделей с использованием иерархического структурированного латентного представления. Работа помогает понять, как можно кодировать геометрию и топологию CAD-объектов для последующего восстановления и генерации.

    Перейти к ресурсу — https://arxiv.org/abs/2401.15563

  5. Mesh R-CNN

    Авторы: Georgia Gkioxari, Jitendra Malik, Justin Johnson.

    Аннотация: Публикация ICCV 2019 описывает систему, которая по изображению обнаруживает объект и строит его трехмерную треугольную сетку. В архитектуре используется промежуточное воксельное представление с последующим уточнением сетки. Работа полезна для сравнения воксельных и mesh-подходов к реконструкции.

    Перейти к ресурсу — https://openaccess.thecvf.com/content_ICCV_2019/html/Gkioxari_Mesh_R-CNN_ICCV_2019_paper.html

  6. Pixel2Mesh: Generating 3D Mesh Models from Single RGB Images

    Авторы: Nanyang Wang, Yinda Zhang, Zhuwen Li, Yanwei Fu, Wei Liu, Yu-Gang Jiang.

    Аннотация: Статья ECCV 2018 посвящена получению трехмерной сетки по одному RGB-изображению. Авторы постепенно деформируют исходную сетку, используя признаки изображения и графовые сверточные операции. Источник полезен для изучения непосредственного восстановления mesh-моделей.

    Перейти к ресурсу — https://openaccess.thecvf.com/content_ECCV_2018/html/Nanyang_Wang_Pixel2Mesh_Generating_3D_ECCV_2018_paper.html

  7. MVSNet: Depth Inference for Unstructured Multi-view Stereo

    Авторы: Yao Yao, Zixin Luo, Shiwei Li, Tian Fang, Long Quan.

    Аннотация: Работа ECCV 2018 представляет нейросетевой метод оценки карт глубины по нескольким изображениям. Для объединения признаков используется трехмерный объем стоимости и 3D-свертки. Публикация полезна для понимания реконструкции по нескольким ракурсам.

    Перейти к ресурсу — https://openaccess.thecvf.com/content_ECCV_2018/html/Yao_Yao_MVSNet_Depth_Inference_ECCV_2018_paper.html

  8. DeepSDF: Learning Continuous Signed Distance Functions for Shape Representation

    Авторы: Jeong Joon Park, Peter Florence, Julian Straub, Richard Newcombe, Steven Lovegrove.

    Аннотация: В статье предлагается представлять форму объекта непрерывной функцией знакового расстояния. Подход позволяет кодировать геометрию, выполнять интерполяцию и восстанавливать форму по неполным или зашумленным данным. Материал полезен для сравнения неявных и воксельных представлений.

    Перейти к ресурсу — https://arxiv.org/abs/1901.05103

  9. Occupancy Networks: Learning 3D Reconstruction in Function Space

    Авторы: Lars Mescheder, Michael Oechsle, Michael Niemeyer, Sebastian Nowozin, Andreas Geiger.

    Аннотация: Авторы предлагают неявное представление поверхности через классификацию точек трехмерного пространства. Публикация полезна для изучения альтернатив дискретным воксельным сеткам способов восстановления геометрии с высокой детализацией.

    Перейти к ресурсу — https://openaccess.thecvf.com/content_CVPR_2019/html/Mescheder_Occupancy_Networks_Learning_3D_Reconstruction_in_Function_Space_CVPR_2019_paper.html

  10. NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis

    Авторы: Ben Mildenhall, Pratul P. Srinivasan, Matthew Tancik, Jonathan T. Barron, Ravi Ramamoorthi, Ren Ng.

    Аннотация: В работе ECCV 2020 представлен метод нейронных радиационных полей для синтеза новых ракурсов по набору изображений. Хотя NeRF ориентирован прежде всего на представление сцен и визуализацию, публикация важна для понимания современных нейросетевых методов восстановления трехмерной информации.

    Перейти к ресурсу — https://arxiv.org/abs/2003.08934

  11. Deep learning-based 3D reconstruction from multiple images: A survey

    Авторы: Chuhua Wang, Md Alimoor Reza, Vibhas Vats, Yingnan Ju, Nikhil Thakurdesai, Yuchen Wang, David J. Crandall, Soon-heung Jung, Jeongil Seo.

    Аннотация: Обзорная статья журнала Neurocomputing систематизирует методы трехмерной реконструкции по нескольким изображениям, включая стереореконструкцию, многовидовые методы и SLAM. Источник полезен для формирования обзора существующих подходов и определения места разрабатываемой системы среди них.

    Перейти к ресурсу — https://www.sciencedirect.com/science/article/pii/S0925231224007896

  12. A Survey of 3D Reconstruction: The Evolution from Multi-View Geometry to NeRF and 3DGS

    Авторы: Shuai Liu, Mengmeng Yang, Tingyan Xing, Ran Yang.

    Аннотация: Обзор 2025 года рассматривает развитие методов трехмерной реконструкции от классической многовидовой геометрии до NeRF и 3D Gaussian Splatting. Публикация помогает ознакомиться с современными направлениями компьютерного зрения и сопоставить различные способы представления сцены.

    Перейти к ресурсу — https://www.mdpi.com/1424-8220/25/18/5748

  13. Advances in Feed-Forward 3D Reconstruction and View Synthesis: A Survey

    Авторы: Авторы указаны на странице публикации Wiley.

    Аннотация: Обзорная публикация 2026 года рассматривает быстрые feed-forward-методы реконструкции и синтеза новых ракурсов, включая point cloud, 3D Gaussian Splatting и NeRF. Полезна для ознакомления с актуальными направлениями развития области.

    Перейти к ресурсу — https://onlinelibrary.wiley.com/doi/10.1111/cgf.70494

Наборы данных и репозитории трехмерных моделей

  1. ABC Dataset: A Benchmark for Realistic CAD Models

    Авторы: Sebastian Koch, Albert Matveev, Zhongshi Jiang, Francis Williams, Alexey Artemov, Evgeny Burnaev, Marc Alexa, Denis Zorin, Daniele Panozzo.

    Аннотация: Набор данных содержит параметрические CAD-модели с геометрической и топологической информацией. Он предназначен для исследований в области обработки и анализа CAD-геометрии и может использоваться для подготовки обучающих и тестовых данных.

    Перейти к ресурсу — https://deep-geometry.github.io/abc-dataset/

  2. ShapeNet: An Information-Rich 3D Model Repository

    Авторы: Angel X. Chang, Thomas Funkhouser, Leonidas Guibas, Pat Hanrahan, Qixing Huang, Zimo Li, Silvio Savarese, Manolis Savva, Shuran Song, Hao Su, Jianxiong Xiao, Li Yi, Fisher Yu.

    Аннотация: Научная публикация описывает крупный репозиторий трехмерных CAD-моделей, организованных по семантическим категориям и снабженных дополнительными аннотациями. Источник полезен для изучения структуры распространенных наборов данных и выбора объектов для экспериментов.

    Перейти к ресурсу — https://arxiv.org/abs/1512.03012

  3. Pix3D: Dataset and Methods for Single-Image 3D Shape Modeling

    Авторы: Xingyuan Sun, Jiajun Wu, Xiuming Zhang, Zhoutong Zhang, Chengkai Zhang, Tianfan Xue, Joshua B. Tenenbaum, William T. Freeman.

    Аннотация: Проект предоставляет изображения реальных объектов, соответствующие им трехмерные модели и материалы для оценки алгоритмов реконструкции по одному изображению. Набор особенно полезен для тестирования методов image-to-3D.

    Перейти к ресурсу — https://pix3d.csail.mit.edu/

  4. Objaverse

    Авторы: Matt Deitke, Dustin Schwenk, Jordi Salvador, Luca Weihs, Oscar Michel, Eli VanderBilt, Ludwig Schmidt, Kiana Ehsani, Aniruddha Kembhavi, Ali Farhadi и соавторы.

    Аннотация: Крупный репозиторий аннотированных трехмерных объектов, включающий версии Objaverse и Objaverse-XL. Предоставляет модели и метаданные, которые могут использоваться для формирования разнообразных наборов трехмерных данных.

    Перейти к ресурсу — https://objaverse.allenai.org/docs/intro/

  5. ModelNet

    Авторы: Zhirong Wu, Shuran Song, Aditya Khosla, Fisher Yu, Linguang Zhang, Xiaoou Tang, Jianxiong Xiao.

    Аннотация: Набор CAD-моделей ModelNet10 и ModelNet40 содержит объекты, распределенные по категориям, и готовые разделения на обучающую и тестовую выборки. Может применяться для экспериментов с классификацией и реконструкцией трехмерных форм.

    Перейти к ресурсу — https://modelnet.cs.princeton.edu/download.html

  6. Thingi10K: A Dataset of 10,000 3D-Printing Models

    Авторы: Qingnan Zhou, Alec Jacobson.

    Аннотация: Набор включает десять тысяч моделей для 3D-печати и отражает особенности реальных сеток, в том числе дефекты, самопересечения и не-многообразную геометрию. Полезен для проверки устойчивости алгоритмов обработки и подготовки трехмерных объектов.

    Перейти к ресурсу — https://arxiv.org/abs/1605.04797

  7. Fusion 360 Gallery: A Dataset and Environment for Programmatic CAD Construction from Human Design Sequences

    Авторы: Karl D. D. Willis, Yewen Pu, Jieliang Luo, Hang Chu, Tao Du, Joseph G. Lambourne, Armando Solar-Lezama, Wojciech Matusik.

    Аннотация: Публикация описывает набор CAD-проектов Fusion 360 и среду для программного построения моделей по последовательностям действий проектировщика. Ресурс полезен для исследования параметрического моделирования и структурированных CAD-данных.

    Перейти к ресурсу — https://dspace.mit.edu/handle/1721.1/145934

Программные средства и документация

  1. PyTorch Documentation

    Авторы: PyTorch Contributors.

    Аннотация: Официальная документация библиотеки PyTorch. Содержит описание тензоров, нейросетевых слоев, средств обучения и работы с графическими ускорителями. Отдельно полезна документация Conv3d для построения трехмерных сверточных сетей.

    Перейти к ресурсу — https://pytorch.org/docs/stable/index.html

  2. PyTorch: Conv3d

    Авторы: PyTorch Contributors.

    Аннотация: Справочная страница слоя трехмерной свертки Conv3d. Описывает входные и выходные тензоры, параметры ядра, шага и дополнения. Может использоваться при реализации нейросетевых моделей, работающих с воксельными данными.

    Перейти к ресурсу — https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv3d.html

  3. TensorFlow: tf.nn.conv3d

    Авторы: TensorFlow Authors.

    Аннотация: Официальное описание операции трехмерной свертки в TensorFlow. Содержит требования к размерности входных тензоров и параметрам фильтров. Полезно при реализации и сравнении трехмерных нейросетевых архитектур.

    Перейти к ресурсу — https://www.tensorflow.org/api_docs/python/tf/nn/conv3d

  4. PyTorch3D Documentation

    Авторы: Meta AI / PyTorch3D Contributors.

    Аннотация: Библиотека предоставляет структуры данных и операции для трехмерного компьютерного зрения: работу с треугольными сетками, преобразования, функции потерь, выборки и дифференцируемый рендеринг. Полезна для расширения функциональности системы обработки 3D-моделей.

    Перейти к ресурсу — https://pytorch3d.readthedocs.io/en/latest/

  5. trimesh Documentation

    Авторы: Michael Dawson-Haggerty и contributors.

    Аннотация: Документация Python-библиотеки для загрузки, анализа и преобразования трехмерных сеток. Включает операции с геометрией, визуализацию и вокселизацию. Может применяться при подготовке STL/OBJ-моделей и создании воксельных обучающих данных.

    Перейти к ресурсу — https://trimesh.org/

  6. Pyrender Documentation

    Авторы: Pyrender Contributors.

    Аннотация: Документация библиотеки для визуализации трехмерных объектов средствами Python. Описывает создание сцен, настройку камер и освещения, а также рендеринг без отображаемого окна. Полезна для автоматической генерации изображений моделей с разных ракурсов.

    Перейти к ресурсу — https://pyrender.readthedocs.io/en/latest/

  7. Open3D Documentation

    Авторы: Open3D Contributors.

    Аннотация: Библиотека для обработки трехмерных данных, включающая инструменты работы с облаками точек, сетками, вокселями, RGB-D-изображениями и восстановления поверхностей. Может использоваться для анализа и постобработки результатов реконструкции.

    Перейти к ресурсу — https://www.open3d.org/docs/

  8. COLMAP Documentation

    Авторы: Johannes L. Schönberger и contributors.

    Аннотация: COLMAP — программный комплекс для Structure-from-Motion и Multi-View Stereo. Поддерживает восстановление положения камер, разреженных и плотных трехмерных структур по наборам изображений. Полезен как пример классического конвейера многовидовой реконструкции.

    Перейти к ресурсу — https://colmap.github.io/

  9. Open CASCADE Technology Documentation

    Авторы: Open CASCADE SAS.

    Аннотация: Документация геометрического ядра Open CASCADE Technology. Описывает построение и обработку B-Rep-геометрии, топологические структуры и операции над твердыми телами. Особенно полезна при изучении преобразования сеточных моделей в CAD-представления.

    Перейти к ресурсу — https://www.occt3d.com/dev/doc/overview/html/index.html

  10. FreeCAD Documentation: Mesh to Shape

    Авторы: FreeCAD Documentation Contributors.

    Аннотация: Страница документации описывает преобразование объекта Mesh в геометрический объект Shape в FreeCAD. Материал полезен для этапа подготовки исходных STL-моделей и изучения перехода от полигональной сетки к геометрическому представлению.

    Перейти к ресурсу — https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Arch_MeshToShape.md

  11. Blender Manual: Mesh Modeling

    Авторы: Blender Documentation Team.

    Аннотация: Официальное руководство Blender по работе с полигональными сетками. Рассматривает редактирование вершин, ребер и граней, а также инструменты моделирования. Полезно для визуальной проверки и постобработки полученных трехмерных моделей.

    Перейти к ресурсу — https://docs.blender.org/manual/en/latest/modeling/meshes/introduction.html

Научные архивы и площадки открытых публикаций

  1. arXiv — Computer Vision and Pattern Recognition (cs.CV)

    Авторы: Cornell University Library.

    Аннотация: Открытый архив научных публикаций, содержащий статьи по компьютерному зрению, анализу изображений и трехмерной реконструкции. Позволяет отслеживать новые методы и получать полные тексты препринтов.

    Перейти к ресурсу — https://arxiv.org/list/cs.CV/recent

  2. CVF Open Access

    Авторы: Computer Vision Foundation.

    Аннотация: Архив открытых публикаций конференций по компьютерному зрению, включая CVPR, ICCV и ECCV. Содержит полные тексты статей, посвященных распознаванию, анализу изображений и восстановлению трехмерной геометрии.

    Перейти к ресурсу — https://openaccess.thecvf.com/

  3. ACM SIGGRAPH Digital Library

    Авторы: Association for Computing Machinery.

    Аннотация: Электронная библиотека публикаций ACM по компьютерной графике и интерактивным технологиям. Особенно полезна для поиска исследований по генерации CAD-моделей, геометрическому моделированию и трехмерной визуализации.

    Перейти к ресурсу — https://dl.acm.org/conference/siggraph
